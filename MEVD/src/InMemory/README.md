# CommunityToolkit.VectorData.InMemory

In-memory provider for [Microsoft.Extensions.VectorData](https://learn.microsoft.com/en-us/dotnet/ai/vector-stores/overview), by the .NET Community Toolkit.

This provider stores vector data in memory and is useful for testing, prototyping, and scenarios where persistence is not required.

## Quick start

Install the NuGet package:

```bash
dotnet add package CommunityToolkit.VectorData.InMemory
```

For more information, see the [Microsoft.Extensions.VectorData documentation](https://learn.microsoft.com/en-us/dotnet/ai/vector-stores/overview).
