# CommunityToolkit.VectorData.SqliteVec

SQLite provider (with [sqlite-vec](https://github.com/asg017/sqlite-vec) extension) for [Microsoft.Extensions.VectorData](https://learn.microsoft.com/dotnet/ai/vector-stores/overview), by the .NET Community Toolkit.

[sqlite-vec](https://github.com/asg017/sqlite-vec) is a SQLite extension for vector search, providing efficient similarity search capabilities in a lightweight, embedded database.

## Quick start

Install the NuGet package:

```bash
dotnet add package CommunityToolkit.VectorData.SqliteVec
```

For more information, see the [Microsoft.Extensions.VectorData documentation](https://learn.microsoft.com/dotnet/ai/vector-stores/overview).
