# CommunityToolkit.VectorData.CosmosMongoDB

Azure DocumentDB (with MongoDB compatibility) provider for [Microsoft.Extensions.VectorData](https://learn.microsoft.com/dotnet/ai/vector-stores/overview), by the .NET Community Toolkit.

[Azure DocumentDB](https://learn.microsoft.com/en-us/azure/documentdb/overview) supports native vector search, enabling AI-powered applications with vector similarity search capabilities.

## Quick start

1. Create an Azure DocumentDB instance via the [Azure portal](https://learn.microsoft.com/en-us/azure/documentdb/quickstart-portal).

2. Install the NuGet package:

```bash
dotnet add package CommunityToolkit.VectorData.CosmosMongoDB
```

For more information, see the [Microsoft.Extensions.VectorData documentation](https://learn.microsoft.com/dotnet/ai/vector-stores/overview).
